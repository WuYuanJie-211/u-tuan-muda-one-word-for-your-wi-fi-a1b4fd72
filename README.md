One word that describes my Wi-Fi: **Mirage**.

Full bars, nothing loads — the signal is right there, the internet is not.

Why this word wins the duel: "Buffering" is the cliché everyone reaches for,
"Ghosting" is vague, "Potato" is a hardware joke, "Dialup" is nostalgia — only
"Mirage" names the exact reversal (bars full, pages dead) and still works as a
network name you'd actually join.
