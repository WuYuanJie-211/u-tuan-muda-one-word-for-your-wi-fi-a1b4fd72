One word that describes my Wi-Fi: **Decorative**.

It is there on the wall, it looks the part, and it does absolutely
nothing. The signal is furniture — nice to look at, useless to use.

Why this word wins the duel: "Buffering" is the cliché everyone reaches for,
"Ghosting" is vague, "Potato" is a hardware joke, "Dialup" is nostalgia —
only "Decorative" names the exact insult (present, pretty, purely ornamental)
and still works as a network name you'd actually join — short enough to type,
strange enough to remember.
