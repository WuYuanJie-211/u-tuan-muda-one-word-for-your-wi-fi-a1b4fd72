One word that describes my Wi-Fi: **Undertow**.

You open your phone to check one thing — an hour later you're still
scrolling, pulled under by a current you never saw. The signal doesn't
shout; it drags.

Why this word wins the duel: "Buffering" is the cliché everyone reaches for,
"Ghosting" is vague, "Potato" is a hardware joke, "Dialup" is nostalgia —
only "Undertow" names the exact pull (invisible, gentle, impossible to
resist once you're in it) and still works as a network name you'd actually
join — short enough to type, strange enough to remember.
